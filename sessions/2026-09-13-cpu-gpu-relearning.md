## 已讲内容

- CPU 发起 GPU 工作，kernel 是 GPU 上执行的计算函数。
- 普通异步提交的返回与 GPU 计算完成是两个事件。
- 异步不等于计算尚未完成；CPU 与 GPU 的进度需要分别判断。
- 通过逐步图示和 5ms/20ms 时间线展示上述机制，未进行 GPU 实测。
